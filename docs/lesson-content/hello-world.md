## 本节要点  认识 JDK、编译与运行，一分钟跑起你的第一个程序。    ## 核心概念  - JDK、JRE、JVM 三者的包含关系  - 源码到运行：javac 编译与 java 执行  - 为什么 Java 能跨平台    ## 关键代码  ```  public class HelloWorld {      public static void main(String[] args) {          System.out.println("Hello, Java!");      }  }  ```    > 注意：代码需 JDK 17 及以上，直接复制即可编译运行。    ## 常见误区  - ['以为 JDK、JRE、JVM 是三选一，实际上是层层包含', '编译和运行用的是不同命令：javac 编译，java 运行']    ## 动手练习  新建一个目录，用记事本写 HelloWorld.java，用 javac 编译后用 java 运行，亲眼看到 .class 文件是怎么生成的。
