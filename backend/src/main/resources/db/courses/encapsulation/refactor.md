## 重构任务

现有代码公开了余额，且存入任何金额都会改写它。请在「习题」里重构账户，把余额改成 `private`，只通过 `getBalance()` 读取余额，通过 `deposit(int amount)` 更新余额。

## 验收规则

- 每次运行输入两个整数，依次为初始余额和存款金额。初始余额在 0 到 `Integer.MAX_VALUE` 之间。
- 只有金额大于 0、相加后也不超过 `Integer.MAX_VALUE` 时，才能存款成功。
- 第 1 行输出 `true` 或 `false`，第 2 行输出操作后的余额。拒绝存款时保持原余额。
- 不改变入口类名 `BankRefactor` 和输入输出格式。

| 输入 | 第 1 行 | 第 2 行 |
| --- | --- | --- |
| `100 25` | `true` | `125` |
| `100 0` | `false` | `100` |
| `100 -20` | `false` | `100` |
| `2147483647 1` | `false` | `2147483647` |
| `2147483646 1` | `true` | `2147483647` |

## 用编译器检查封装

判题会比对运行结果。通过后再验证字段访问：在 `BankRefactor.main` 中临时写 `account.balance = -1;` 并运行，确认编译失败，随后删掉这行。
