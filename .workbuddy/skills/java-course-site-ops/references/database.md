# 数据库参考（KingbaseES V8R6）

实例：`D:\Kingbase\data`，端口 `54321`，dbmode=`oracle`，字符集 UTF8。
JDBC URL：`jdbc:kingbase8://127.0.0.1:54321/javacourse?currentSchema=public&characterEncoding=UTF-8`
驱动：`backend/lib/kingbase8-8.6.0.jar`（本地 lib，不走 Maven 中央仓库）。

## 表清单

| 表 | 用途 | 关键约束 |
|---|---|---|
| `app_user` | 用户与登录 | `uk_app_user_username`；`password_hash` + `salt` 为 PBKDF2-HMAC-SHA256（120000 轮，16 字节盐） |
| `user_session` | 会话令牌 | `uk_user_session_token`；令牌为自实现 HMAC-SHA256，载荷 `userId\|username\|role\|issuedAt\|expireAt\|nonce` |
| `course` | 课程 | `uk_course_slug`（slug 是前端路由参数） |
| `course_module` | 课程模块 | `fk_module_course` 级联删除 |
| `lesson` | 课时 | `uk_lesson_slug`；`content` / `content_html` 为 CLOB |
| `code_snippet` | 代码片段 | `fk_snippet_lesson` 级联删除 |
| `knowledge_point` | 知识点 | `uk_kp_name` |
| `lesson_knowledge` | 课时↔知识点多对多 | 复合主键 `(lesson_id, kp_id)` |
| `qa_item` | 题目 | `options_json` / `answer_key`；`qa_type` 默认 `SINGLE_CHOICE` |
| `resource_file` | 附件 | `file_path` 为相对路径 |
| `search_index` | 搜索索引 | `target_type` + `target_id` 定位目标；`tokens` 存应用层分词结果 |
| `learning_progress` | 学习进度 | `uk_lp_user_lesson`；`progress_pct` 0-100，`completed` 为 SMALLINT 0/1 |
| `user_favorite` | 收藏 | `uk_uf_user_lesson` |
| `ai_chat_session` | AI 会话 | `agent_key` 默认 `whale`（鲸鲸助教） |
| `ai_chat_message` | AI 消息 | `citations` 存引用 JSON 字符串；`latency_ms` 记录耗时 |
| `generation_log` | AI 建站审计 | `task_id` 串联一次生成任务 |

## 兼容性约束（写在 schema.sql 头部，改表时必须遵守）

**已实测可用**：`tsvector` + GIN 索引、`json` / `jsonb`、`float4[]` 及数组切片、物化视图、窗口函数、`ON CONFLICT`（upsert）。

**已实测不可用**：
- `vector` 扩展（`share/extension/vector` 不存在）→ embedding 存 `float4[]` 或 `jsonb`，在应用层算余弦相似度。
- `zhparser`（需 superuser 才能安装）→ 全文检索走应用层分词，不依赖数据库分词器。

**字段名避开保留字**：`user`、`level`、`order`、`session`、`comment`、`size`、`type`。新字段若与这些同名，用 `xxx_` 后缀（如 `sort_order`、`file_size`、`file_type`、`target_type`）。

**类型约定**：自增主键用 `BIGINT GENERATED BY DEFAULT AS IDENTITY`（不依赖序列）；时间统一 `TIMESTAMPTz`；大文本用 `CLOB`；布尔语义用 `SMALLINT` 0/1。

## 迁移写法

本实例 `dbmode=oracle` 对 `CREATE TABLE IF NOT EXISTS` 支持有限。幂等迁移优先用：

```sql
DO $$
BEGIN
    EXECUTE 'CREATE INDEX idx_xxx ON lesson (module_id)';
EXCEPTION WHEN others THEN
    RAISE NOTICE 'index exists, skipped';
END $$;
```

或先 `DROP ... IF EXISTS` 再建。

## 常见报错速查

| 现象 | 根因 | 处理 |
|---|---|---|
| `Unable to rename jar` | 旧后端进程占用 jar（Windows 文件锁） | 打包前 `Stop-Process` 杀 `javacourse-server` 进程 |
| 实例起不来，报权限错误 | License 共享内存用 `Global\kingbase:`，需 `SeCreateGlobalPrivilege` | 以管理员运行 `scripts/kb_start.sh` |
| `relation "xxx" does not exist` | schema 未 bootstrap | 跑 `scripts/kb_bootstrap.sh` |
| 查询 500 且日志是 `AS x AS y` | SQL 别名链式书写非法 | 别名只能一层，全库 `grep -rn "AS [a-z_]* AS "` 排查 |
| 中文分词无召回 | 无 zhparser | 走 `search_index.tokens` 应用层分词 |

## 常用排查 SQL

```sql
-- 某用户的学习进度
SELECT l.title, p.progress_pct, p.completed, p.last_seconds
FROM learning_progress p JOIN lesson l ON l.id = p.lesson_id
WHERE p.user_id = ? ORDER BY p.updated_at DESC;

-- 重建搜索索引（应用层分词）
SELECT id, target_type, target_id, title FROM search_index ORDER BY updated_at DESC LIMIT 20;

-- AI 调用审计
SELECT model_name, latency_ms, result_status, created_at
FROM generation_log ORDER BY created_at DESC LIMIT 20;
```
