2.4 泛型与类型擦除

面向对象与集合 · 第 2 模块 · 时长 32 分钟 · 难度 中级 · 最后更新 2026-10-18
// 编译器擦除 type 参数，只保留上界
public class Box<T extends Number> {
  private T value;
  public T get() { return value; }
}
// 运行时只有 Box 一个类
Box<Integer> a = new Box<>();
Box<String>  b = new Box<>();
// a.getClass() == b.getClass() → true
// AI 助教
问：为什么泛型不能用于基本类型？
答：类型擦除后无法区分 int/Integer 装箱语义，故编译器统一转为包装类。
